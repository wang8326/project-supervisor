## 2. 核心价值排序

1. 数据、账号、资产和凭证安全。
2. 已有功能和完整用户流程稳定。
3. 用户操作简单且错误可恢复。
4. 成本与资源消耗透明。
5. 在门禁可靠后扩大功能范围。

## 3. 不可退化的用户流程

- 待补充项目核心流程。默认保留相关功能、内容、字段、按钮与完整操作旅程；未经用户明确授权，不删、隐藏、禁用、缩窄或静默降级，安全/简化不构成删除授权。高级流程、必要错误处理及有效测试同样保留。
- 涉及配置时，包括配置保存到首个用户消费及失败恢复；新建或已授权调整的非技术管理流程优先呈现必要业务字段和一个保存启用主动作，内部校验尽量自动执行，不削弱安全、费用约束及既有字段/按钮/高级流程的可达性。
- 改共用代码先检查实际调用者；修改前后用短的“保留/明确修改/明确移除”对照，未授权移除为空。复用已有验收与测试，不创建额外长审计文档。

## 4. 永久技术与安全边界

- 技术栈与运行环境：待核实。
- 认证、数据、媒体和凭证边界：待核实。

## 5. 决策边界

负责人决定用户行为、成本、数据安全、人员权限和发布风险方面的产品选择。Codex 负责技术方案、最小范围、相称验证、风险判断和通俗交付。遵从用户当前明确要求与适用的全局/项目规则；已授权范围内完成必要技术选择，只对真实行为取舍缺少授权的部分询问。
